# Технический прогон обучения — 2026-10-24

**Конвейер работает; пригодность модели к управлению Wave не проверялась.**
На Qwen2.5 0.5B Instruct выполнены два шага LoRA, адаптер сохранён и повторно
загружен. Кандидат 1.5B не обучался: для него проверена только токенизация.
Модель в приложение не установлена, holdout и публичный v1 не использовались.

## Что запускалось

Linux, Intel Core i3-10100F, 15 890 MiB RAM, GPU недоступен. Python 3.12,
CPU-only PyTorch 2.9.0, два потока, float32, batch size 1. База:
`Qwen/Qwen2.5-0.5B-Instruct`, revision
`7ae557604adf67be50417f59c2c2f167def9a775`.
Полные версии, настройки и хеши — в [result.json](result.json).
Файлы скачанного снимка дополнительно [проверены SHA-256](base-files.json).
Настоящий запуск профиля 1.5B [отклонён проверкой RAM](qwen25-15-resource-check.json)
до загрузки весов: доступно 6,23 GiB при заданном пороге 10 GiB.

LoRA rank 4, alpha 8, q_proj/v_proj, learning rate 1e-4, без dropout,
gradient checkpointing, clip norm 1. Из 494 303 104 параметров модели с адаптером
обучались 270 336. Изменились 96 тензоров адаптера. Базовые параметры исключены
из optimizer; повторный расчёт с отключённым адаптером воспроизвёл исходный loss.
Полное побайтовое хеширование каждого базового тензора после обучения не выполнялось.

Использованы **две** обучающие строки: `train-transport-roundtrip-ru:1` и
`train-transport-roundtrip-en:1`, обе о паузе. Каждая содержит 18 целевых токенов.
Dev — тоже только две строки: первые решения `dev-readonly-library-audit` RU/EN.
Это 2 из 128 train-примеров и 2 из 26 dev-примеров, не эпоха по всему корпусу.

точность. Снижение teacher-forced loss не означает правильных действий агента.

друга. Таблица относится только к финальному запуску, а не к выбору лучшего результата.

## Токенизация и проверки

Все train/dev данные проверены настоящими токенизаторами
[0.5B](tokenization-qwen25-05.json) и [1.5B](tokenization-qwen25-15.json).
У обоих получены 128 train / 26 dev примеров; максимальные длины 1993 / 1537 токенов.
Весь контекст сохранён, потери применяются только к завершающему ответу.
Для экономии RAM сокращена выходная проекция masked-позиций, не входная история.

Прошли 15 Python-тестов: 9 проверок данных/маски, 4 ограничения запуска и
2 настоящие проверки autograd/сохранения на маленькой случайной Qwen2 без сети.
Последние сравнивают loss **и градиенты** оптимизированного и полного расчёта,
изменение LoRA, неизменность базовых тензоров тестовой модели и загрузку адаптера.
Новый запуск также проверяет точную ревизию в `adapter_config.json`.
В обычный CI добавлены 13 тестов, не требующих установки ML-библиотек.
