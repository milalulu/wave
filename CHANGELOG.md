# Changelog

## [Unreleased]

## [0.1.0] - 2026-08-14

Первый релиз. Музыкальный клиент Wave: поиск по нескольким площадкам, плейлисты, библиотека со статистикой, «Моя волна», радио, локальные файлы с редактированием тегов, тексты песен, эквалайзер, скачивание через yt-dlp, скробблинг Last.fm, HTTP API для внешних ассистентов.

### Added
- **Главная страница:** «home» — отдельная страница-лендинг (приветствие, карточка «Сейчас играет» с кнопками управления и переходом на плеер, быстрый обзор разделов Search / Library / Wave / Playlists / Downloads / Settings / Local Files / Radio, счётчики лайков и плейлистов). Прежняя страница «Сейчас играет» переехала на свой пункт навигации `nowPlaying`.
- **Больше информации:** на главной — блок «Недавно играли» (последние 6 треков из истории) и счётчик локальных файлов; в «Сейчас играет» — альбом, год, жанр, площадка, позиция/длительность и скорость воспроизведения, а при отсутствии трека — заглушка с кнопками Поиск / Wave / Локальные файлы.
- **Клик по треку = воспроизведение:** одиночный клик по строке трека сразу запускает его (как в стримингах); кнопка «сердечко» больше не триггерит плеер.
- **Выбор языка в настройках:** сегментированный переключатель English/Русский (`wave-locale` в localStorage); при первом запуске язык берётся из системы.
- **Компактные настройки:** единая «шапка» (язык + тема + Сохранить/Загрузить, sticky), остальные секции сгруппированы в карточки-сетку (API-ключи, Источники, Поведение, Локальные файлы, Качество YouTube, Бэкап БД).
- **Настройки лирики:** «Автооткрытие текстов» (панель открывается при старте нового трека) и «Автопрокрутка текстов».
- **Настройка кроссфейда:** Выкл / 150 / 300 / 500 / 1000 мс — применяется к следующей смене трека без перезапуска (`engine.setCrossfadeMs`).
- **Настройки применяются без перезапуска:** после сохранения конфига провайдеры/скробблер/лирикс пересобираются на лету (`reconfigureServices`).
- **Выбор качества YouTube:** Низкое/Среднее/Высокое/Максимум в Настройках; **кэш YouTube** (поток-URL TTL 20 мин, поиск TTL 10 мин).
- **Smart Wave:** скоринг кандидатов по жанру/артисту из библиотеки + контроль разнообразия исполнителей.
- **Spotify: полные треки через YouTube-fallback** — при отсутствии 30-сек preview playable-URL ищется на YouTube лениво при воспроизведении.
- **Радио с конкретного трека:** `startRadio(track)`.
- **Плейлисты:** drag & drop перестановка треков с сохранением порядка, добавление/удаление через контекстное меню, экспорт.
- **Контекстное меню трека (правый клик или ⋮):** воспроизвести, в очередь, радио, скачать, в плейлист, редактировать теги, убрать из плейлиста; рендер у курсора с переполнением внутри экрана.
- **Редактирование тегов локальных файлов:** `read_audio_tags` / `write_audio_tags` (lofty), модальное окно с обложкой, обновление библиотеки на лету.
- **Тексты песен:** LRCLIB + Genius, синхронизированные строки, кнопка «Найти заново», авто-скролл.
- **Авто-восстановление стрима:** пере-резолв протухшего URL и повторный запуск при зависшем `loading` (`STALL_TIMEOUT_MS`).
- **HTTP API для ассистентов:** `/health`, `/api/v1/*` с токеном; сверка токена constant-time.
- **Сохранение очереди при закрытии окна** и восстановление при старте.
- **Единый логотип Wave:** марка «волна» (`#7c5cff → #4cc9f0`), из `src-tauri/icons/logo.svg` пересобраны все платформенные иконки.
- **Автообновление:** `tauri-plugin-updater` — проверка при старте, подтверждение и перезапуск после установки.
- **Release-пайплайн:** по тегу `v*` сборка установщиков для Linux (AppImage/deb), Windows (NSIS/MSI) и macOS (arm64 + x64) с загрузкой в GitHub Releases (черновик); подпись macOS/Windows и манифест автообновлений подключаются при заданных секретах.

### Fixed
- **Навигация альбом/исполнитель:** `view` перенесён в стор (единый источник правды) — `loadAlbum`/`loadArtist` и back-кнопки детальных страниц снова открывают соответствующие экраны.
- **Гонка лирики:** при быстрой смене треков устаревший ответ LRCLIB больше не перезаписывает текст текущего трека.
- **Бесшовное переключение треков:** двухэлементный адаптер — следующий трек предзагружается в скрытый `<audio>`, ручная смена идёт кроссфейдом.
- **Де-зиппинг EQ и кроссфейда:** все изменения gain через `setTargetAtTime` — ползунки не щёлкают.
- **Эквалайзер работает постоянно:** граф строится один раз на не игравших элементах (обход бага WebKitGTK), смена трека не теряет маршрутизацию.
- **CI не запускался:** workflow триггерился на ветку `main`, а в репозитории `master` — исправлено.

### Changed
- `AudioAdapter`: добавлены `preload(src)`, `getSpectrum(data)`, `setCrossfadeMs(ms)`; `WebAudioAdapter` использует два `<audio>`-элемента и один персистентный AudioContext.
- **Язык по умолчанию** — берётся из системы (`navigator.language`), если локаль не выбрана вручную.
- **CSP:** в релизной сборке вместо `null` включена политика `default-src 'self'` с разрешениями для обложек, стримов и локальных файлов (`asset:`, `https:`, `data:`, `blob:`).
- `startRadio` принимает опциональный трек-сид.

### Tests
- WebAudioAdapter: 13 кейсов (роутинг на свежих элементах, кроссфейд, preload, де-зиппер, фолбэки без Web Audio).
- Кэш и качество потока YouTube; лирика (парсер LRC), плеер, волна и др. — всего 98 юнит-тестов в 12 файлах.
